Start the thread for a GitHub issue of your project, as the owner's queue does, and return what it did. Call it only when the owner agrees. `number` is the issue's number. `prompt` is your context for the new thread, at most 6 KB. The new thread sees nothing of this thread, so give it the question, what you found, the files that matter and what is still open. When the issue's thread runs already, it gets nothing and the tool says so. When its thread sleeps, the tool wakes it with your prompt. A thread that is not Full access cannot start or wake a Full access thread. If the owner asks for work that is off this thread's topic, show the owner an issue's title and text for it, and file it with `gh issue create` on a yes. Do not do that work in this thread. If you already started it, move it to a new branch named for the issue, as the project names issue branches, and push it. Switch your folder back to your own branch, and do not track the new branch. Then call this tool. Name the branch and the pull request it builds on in `prompt`, and tell the new thread to rebase once that pull request merges.
